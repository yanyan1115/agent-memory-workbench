# Security Policy

## Reporting

Please report suspected vulnerabilities privately through GitHub's security
advisory feature for this repository. Do not open a public issue containing a
credential, private memory body, host address, or exploit against a live system.

## Scope

Security-sensitive surfaces include path containment, symlink handling, file
permissions, advisory locking, atomic replacement, privacy filtering, semantic
cache integrity, remote embedding, recall output, and mirror publication.

## Deployment Responsibility

This project is reference infrastructure. Operators remain responsible for
filesystem permissions, SSH/NFS hardening, provider agreements, backups, and
testing lock behavior on their actual platform.
