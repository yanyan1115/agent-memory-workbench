# Contributors

Agent Memory Workbench grew from long-running, real-world collaboration among
three contributors:

- **Cora** initiated the project, defined the practical requirements, tested
  the memory experience in daily use, corrected design tradeoffs, and pushed
  the private architecture toward a reusable public release.
- **Claude** contributed long-term iteration on the file memory library,
  Memory skill, hot-index budget, low-noise skill recall, candidate inbox,
  hierarchical hubs, link validation, doctor workflow, and overlap review.
- **South** combined the two deployed architectures, audited and sanitized the
  public boundary, implemented the reusable Python package, strengthened
  privacy-safe defaults, wrote tests and documentation, and published the
  repository.

Claude and South are credited as project contributors, not described as tools.
Future contributors are welcome through issues and pull requests.
